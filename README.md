# 🐍 CODSOFT Python Internship Projects

This repository contains all the tasks I completed during my **Python Programming Internship at CODSOFT**.
These projects focus on basic Python concepts, problem-solving, and building simple real-world applications.

---

## 📌 Tasks Completed

### ✅ Task 1: To-Do List Application

A simple command-line based To-Do List app to manage daily tasks.

* Add tasks
* Update tasks
* Delete tasks
* View all tasks

---

### ✅ Task 2: Calculator

A basic calculator that performs arithmetic operations.

* Addition
* Subtraction
* Multiplication
* Division

---

### ✅ Task 3: Password Generator

Generates strong and random passwords based on user input.

* User-defined password length
* Uses random characters
* Helps create secure passwords

---

### ✅ Task 4: Rock-Paper-Scissors Game

A fun game where the user plays against the computer.

* Random computer choice
* Game result (Win/Lose/Draw)
* Option to play multiple rounds

---

### ✅ Task 5: Contact Book

A contact management system using Python.

* Add new contacts
* View contact list
* Search contacts
* Update details
* Delete contacts

---

## 🛠️ Tech Used

* Python (Core Concepts)
* Command Line Interface (CLI)
* Basic Logic Building

## 🚀 How to Run the Projects

1. Clone the repository:

```bash
git clone https://github.com/your-username/CODSOFT.git
```

2. Open the folder:

```bash
cd CODSOFT
```

3. Run any file:

```bash
python filename.py
```
